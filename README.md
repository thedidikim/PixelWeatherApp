# Pixel Weather App

A pixel art-themed responsive weather forecast web app that consumes the National Weather Service API.

## Technologies

- HTML5
- CSS3
- JavaScript
- jQuery
- National Weather Service API

## Features

- Latitude and longitude forecast lookup
- Automatic location detection
- Responsive three-card forecast layout
- NWS weather icons
- Temperature and wind information

## Live Demo

https://thedidikim.github.io/PixelWeatherApp/

## Project Context

Originally developed as an IT-634 Distributed Application Development course activity at Southern New Hampshire University.
